# Evidence Archive

last checked: 2026-09-02

이 폴더는 로수젯 PM 학습 사이트에 사용한 가이드라인, fact sheet, landmark trial, 로수젯 직접/인접 근거를 추적하는 아카이브다. PDF 원문을 복제하지 않는다. 대신 공식 링크, PubMed/PMC 링크, 확인 상태, PM 활용, claim guardrail을 기록한다.

## 사용 원칙

- 원문 우선순위: 학회 공식 페이지, journal full text, PubMed, registry, 회사 보도자료 순서로 본다.
- 동일 연구라도 `product direct`, `strategy`, `class`, `context`를 구분한다.
- 역학 자료는 시장 크기와 funnel에 사용하고, 제품 효과 claim으로 확장하지 않는다.
- 급여가격은 HIRA 최신 약제급여목록 및 급여상한금액표 적용일을 확인한 뒤 외부 자료에 사용한다.
- 새로운 구조 항목이 들어오면 데이터 JS와 이 폴더를 같이 업데이트한다.

- [rosuzet_and_nonstatin_evidence.md](rosuzet_and_nonstatin_evidence.md): EROICA, REMBRANDT, SWITCH, ROSETTA-Stroke, RACING subgroup, nonstatin residual risk 근거

- [source_inventory.md](source_inventory.md): 찾은 원문과 추가 확인이 필요한 원문 목록
